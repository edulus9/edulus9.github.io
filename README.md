## How to do things

### Get started

1. Clone the repo
2. Run `npm install`
3. Run `npm dev`
4. Open your browser and go to `http://localhost:3001`
5. Enjoy the website!

### Deploy a new version

1. Switch to the `develop` branch
2. Run `npm run install`
3. Run `npm run predeploy`
4. Run `npm run deploy`
5. Wait for the deployment to finish
